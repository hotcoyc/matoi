# Phase B: TUI с prompt_toolkit -- план реализации

## 1. Установка и базовый промпт
- 1.1. Добавить `prompt_toolkit` в зависимости
- 1.2. Заменить `rich.prompt.Prompt.ask` на `prompt_toolkit.PromptSession`
- 1.3. Кастомный промпт `>` с цветом (зелёный когда ready, жёлтый когда агенты работают)
- 1.4. Индикатор проекта и PM в промпте: `[matoi/startup-pm] >`

## 2. Мультилайн ввод
- 2.1. Enter = отправить, Alt+Enter = новая строка
- 2.2. Визуальная подсказка "alt+enter for newline" в первой сессии
- 2.3. Автодетект мультилайна: если строка заканчивается на `:` или `{` -- ждать продолжения

## 3. Автокомплит команд
- 3.1. `/` триггерит автокомплит
- 3.2. Список: /help, /team, /cost, /commit, /quit, /history, /agents
- 3.3. Автокомплит имён агентов после `@` (например `@backend-engineer`)
- 3.4. Fuzzy matching (не только prefix)

## 4. История ввода
- 4.1. Стрелки вверх/вниз -- навигация по истории сессии
- 4.2. Сохранение истории между сессиями в `~/.matoi/history`
- 4.3. Ctrl+R -- поиск по истории

## 5. Вывод ответов агентов
- 5.1. Markdown rendering через `rich.markdown.Markdown` для ответов
- 5.2. Подсветка кода в блоках ``` через `rich.syntax.Syntax`
- 5.3. Разделители между агентами (rule с именем и типом)
- 5.4. Streaming + markdown: рендерить после завершения каждого агента

## 6. Статус-бар внизу
- 6.1. Bottom toolbar через `prompt_toolkit`
- 6.2. Показать: PM name | team size | session cost | tokens used
- 6.3. Обновляется после каждого вызова API

## 7. Keybindings
- 7.1. Ctrl+C -- отменить текущий ввод (не убить сессию)
- 7.2. Ctrl+D -- выход (как /quit)
- 7.3. Ctrl+L -- очистить экран
- 7.4. Tab -- автокомплит

## 8. Интеграция с существующим кодом
- 8.1. Заменить REPL loop в `session_repl.py` на prompt_toolkit сессию
- 8.2. Сохранить всю бизнес-логику (_run_task, _commit_flow, _recommend_team)
- 8.3. Тесты: проверить что non-interactive mode (`matoi run "task"`) не ломается
